# SEO listing push — 2026-10-26

Content: seo/content.json (207 ASINs, en+ar: t, b[5], d, k), generated by seo/content*.py + final.py, checked by validate.py.

## Mechanism (Seller Central listing editor)
- Open /interactive/listing/workflow/edit/product_identity?sku=SKU&asin=ASIN&reduceVariationAttributes=true
- Hook XHR/fetch to POST /abis/ajax/edit; rewrite the urlencoded body:
  delete item_name/bullet_point/product_description/generic_keyword keys, re-add ONLY in the
  listing's own language (body param listingLanguageCode), #1..#5 bullets, and blank #2 / bullets #6-#10.
- Make a dummy edit on item_name (value + ' -' if unchanged) so "Submit Edits" enables; click it.
- Response {"status":"SUCCESS"} = accepted (live within ~24h).

## Lessons
- Do NOT send both languages in one submit: on en_AE listings Amazon stored the Arabic as English
  (Arabic title + 10 bullets on EN page); on ar_AE listings it creates a draft error 100144.
- Partial update: attribute instances not sent are kept -> always blank #6-#10 bullets and #2 instances.
- Listing language is fixed per saved listing (201 are en_AE, 6 mugs ar_AE); UI locale doesn't change it.
- Draft-error listings: open Description, click "Remove last" until 5 bullets, then Submit (button text "Submit").
- After a failed attempt the page is dirty -> navigate with force (beforeunload dialog).
- Error 99300: description promo sentence ("order now, fast delivery") is rejected.
- Error 8541: field value language must match listing language.
